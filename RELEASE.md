# Release Notes

This package is source-build ready. For an official ROS release later, prepare:

1. A public source repository.
2. Correct maintainer email in `package.xml` and `setup.py`.
3. A released version in `package.xml`, `setup.py`, and `CHANGELOG.rst`.
4. A bloom release repository.
5. A rosdistro pull request for the target ROS distribution.

For first public GitHub upload, the minimum useful checklist is:

- `README.md`
- `LICENSE`
- `CHANGELOG.rst`
- `package.xml`
- `setup.py`
- `setup.cfg`
- `resource/domain_fleet_gateway`
- `domain_fleet_gateway/`
- `config/`
- `launch/`
- `test/`
